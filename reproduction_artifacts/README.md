# 复现产物目录

本目录集中保存复现过程中生成的、便于复核但不属于模型源码的文件。

目录约定：

- `milestone_01/`：环境报告与结构认知材料；
- `code_walkthrough/`：原仓库代码导览手册与小样本贯通摘要；
- 后续里程碑使用同样的两位编号，例如 `milestone_02/`；
- 大型原始数据集放在 `datasets/`，预处理数据和模型权重的位置在对应里程碑单独约定；
- 可重复执行的工具脚本统一放在仓库根目录的 `scripts/`。
- `MILESTONE_LOG.md`：后续可复核节点的事实日志，不定义当前状态或下一步；
- `plan_history/`：主计划历史快照，仅用于追溯，不具有现行执行效力。

每个产物应能从对应里程碑摘要或 `MILESTONE_LOG.md` 追溯到生成命令和验收结论。当前状态与执行入口只由仓库根目录 `REPRODUCTION_PLAN.md` 定义。

凡涉及代码变更，对应里程碑手册必须记录：修改位置、为什么原实现不满足要求、为什么采用当前方案、是否改变实验语义、验证命令。优先解释可迁移的排障原则，而不是逐行复述代码。
