# FFTCN ACM 式学习指南

本目录存放“如何完成练习”的教学材料，与正式源码、实验产物和模型输出分离。

## 固定学习流程

每个里程碑按以下顺序学习：

1. 只读题目、输入输出和约束；
2. 补齐本题需要的 Python/NumPy 基础；
3. 用纸笔推演小样本；
4. 直接阅读带块级/行级注释的完整实现；
5. 遮住答案，用自己的话复述输入到输出的数据流；
6. 在练习文件中手敲、模仿或独立重写；
7. 完成当前内部步骤规定的整组核心代码，再运行该步骤的聚焦测试；
8. 根据 traceback 对照参考代码解释差异；
9. 运行全部测试并记录可迁移经验。

完整答案从教程对应题目中直接提供，并同步保存在带详细注释的 `reference_solution.py`；但不会自动写入 `data/` 或 `models/`，也不会被正式训练代码导入。

所有新教程在交付用户练习前，必须逐项通过 `learning_guides/COMMENT_QUALITY_GATE.md`。语法正确和测试通过只能证明代码正确，不能替代对“每个非平凡语句是否解释做什么、为什么、形状/类型怎样变化”的人工审读。

## 参考代码复杂度原则

- 主答案优先展示“最小、准确、能体现算法主线”的实现；
- 只保留算法正确性必需内容，例如同步 mask、全 W 分支、唯一 `record_id` 和局部随机源；
- 穷举或重复的 shape、异常标签、NaN、空集合等生产环境防御放在“工程加固（选读）”；能阻止当前固定运行链发生静默语义错误的检查仍保留在核心代码；
- 不为了显得健壮而让初学者先读大量与核心算法无关的条件判断。

## 数据策略与模型结构的里程碑边界

- 里程碑 3 保存未经重复采样的正式 train/validation/test 数据，保留真实类别分布；
- 里程碑 5–7 只学习模型前向、形状和梯度，不在模型类内部执行过采样；
- 类别不平衡、仓库 `offset_resample`、仅训练集增强、两分支预训练和完整模型微调统一在里程碑 8 讲解与实现；
- 验证集和测试集绝不执行过采样，否则评估指标不再反映真实分布；
- 仓库的 `offset_resample` 是带随机时间偏移的过采样增强，不会把各类数量严格变成完全相等。

## 卡题时如何提问

建议提供：

- 当前正在实现的函数；
- 已写代码；
- 聚焦测试的完整错误；
- 你认为错误发生在哪一步。

这样可以继续按提示层级推进，而不是直接覆盖你的实现。
